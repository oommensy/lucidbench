# v0.3.1 Construct Crosswalk

This document records why the LucidBench v0.3 annotation schema was revised before human pilot annotation continued.

## Design change

The original rubric used broad fields for awareness, agency, control, metacognition, waking memory, sensory richness, emotion, and stability. Expert consultation and literature review indicated that several of those fields combined constructs that prior work treats separately.

The v0.3.1 schema therefore preserves the reproducible 120-report pilot sample and blinding design while revising the **annotation constructs**.

| Original LucidBench field | v0.3.1 treatment | Literature anchor |
|---|---|---|
| awareness | renamed/refined to `lucid_insight` | LuCiD INSIGHT; DLQ awareness items |
| agency | renamed `intentional_agency` and kept separate from outcome | MACE choice/focused attention; LDCQ discussion of agency |
| control | split into `control_attempt`, `control_success`, `control_domain` | LUSK control items; LDCQ multidomain control |
| metacognition | decomposed into `internal_commentary`, `self_reflection`, `state_reasoning` | MACE; LuCiD discussion of reflective thought vs dream-state insight |
| waking_memory | retained; prospective intention separated | LuCiD MEMORY; DLQ remembrance; LUSK waking-memory item |
| sensory richness | retained as modality indicators | Dream Intensity Scale / dream vividness literature |
| emotion | retained as intensity + valence | LuCiD emotion factors; MADRE and related dream-emotion measures |
| stability | split into instability, loss of lucidity, awakening | LUSK problems/maintenance items; LDCQ cognition-control items |

## New transition layer

A second layer was added to represent pathways into lucidity:

`anomaly_present → anomaly_noticed → internal_commentary/state_reasoning/reality_testing → lucid_insight or dream_rationalization`

This enables comparison of:

1. reports with no transition toward lucidity;
2. **near-lucid / failed-transition** reports, where anomaly-related reflection occurs without explicit lucid insight;
3. reasoning-based lucid transitions;
4. spontaneous/intuitive lucid transitions; and
5. wake-initiated lucid transitions.

This transition representation is an exploratory LucidBench operationalization. Existing instruments motivate its component constructs, but LucidBench does **not** claim that this exact sequence is an established validated scale.

## Important measurement limitation

Retrospective dream narratives are incomplete descriptions of experience. A cognitive event that is not mentioned may nevertheless have occurred. Accordingly, most zero codes mean **not evidenced in the report**, not demonstrated absence.

The human pilot should test whether these distinctions can be coded reliably before any large-scale model training or phenomenological claims are made.
