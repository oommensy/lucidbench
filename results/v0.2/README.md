# LucidBench v0.2 generated results

These aggregate results were generated by `python -m lucidbench.experiments --config configs/v0.2.yaml`. The input corpus is Remington Mallett's *A large corpus of lucid and non-lucid dream reports*, Zenodo DOI [10.5281/zenodo.19161757](https://doi.org/10.5281/zenodo.19161757), licensed **CC BY-NC 4.0**. Dataset-derived coefficient tables in this directory are shared under the same CC BY-NC 4.0 terms, with attribution to the dataset creator. Other project source code remains under the repository's MIT License.

The coefficient tables contain unigram model associations supported by at least ten training authors; they omit bigrams and report-level predictions. `length_matching.csv` records available and retained counts per label and length bin. Coefficients are correlational model associations, not causal explanations or validated scientific findings. The source data, author identifiers, and report-level predictions are not included in this repository.

The results are aggregate research outputs, not a substitute for downloading the source dataset and rerunning the documented procedure. See `docs/RESEARCH_PROTOCOL.md` for the experiment and limitations.
